📱 スマホ
・左下の まる（画面の 左半分は どこでも）を なぞる → その向きへ うごく（上=前／下=後ろ／左右=よこ）
・右下の まる を 倒す → まわりを 見まわす（パソコンの マウスに あたる もの）。左右の まるは 同時に つかえます
・まるの 外がわ（右半分）を なぞっても 今までどおり 見まわせます。⚙「スマホの 見まわし方」で なぞる だけにも できます
・▲▼ ボタン → 上・下へ（左右は 同時に つかえます）
💻 パソコン（見まわし方は ⚙で 2つから えらべます）
・クリックで固定（おすすめ）→ カーソルが 中央に固定＝ずれません・マウスで 見まわす・Escで解除・クリックで 正面の星をひらく
・クリックなし→ マウスを 動かすと 見まわす（カーソルは 自由に動きます）
・感度は ⚙「マウス感度」／上下が逆なら ⚙「上下の向きを 反転する」
・W A S D（矢印キー）→ 前後左右、Space／Shift → 上下、ホイール → 前後
・W を 2回つづけて押して、2回目を おしっぱなし → ぐんと 速くなります（はなすと もどります）
・スマホは 左半分の まるを いちばん外まで 倒す → 速くなります
・速さ・ゆれ・かたむきは ⚙で かえられます（酔いやすい方は「🍃 快適モード」）
・🛩️オートクルーズ（右上のボタン、または C キーで切り替え）→ そうさしなくても ゆっくり前へ すすみます。ひかりの輪コース中は 次の輪へ 針路を自動でととのえます。とめたい時は S／↓（うしろ）でブレーキ、そうさすれば いつでも自分の操作にもどります
共通：🔍さがす→星まで とぶ／🎬めぐる→じどうで 作品を まわる／星にふれる → 作品がひらいて 曲がながれます
・⚙「🌍 せかいを えらぶ」→ うちゅう（星の海）と そら（くもの海）を いつでも 行き来できます。作品は どちらでも 同じで、景色と とびごこちだけ かわります

🙈 画面を すっきりさせる（じょうほうが 多いと 感じる時）
・パソコンは H キー → じょうほう（✨すれ星・🧭今日の航路・⚡とぶちから・🔆のこりの環・ミニマップ・だいめい）が まとめて 消えます。もう一度 H で もどります
・スマホは ⚙ の「🙈 画面を すっきりさせる」から 同じことが できます
・1つずつ 決めたい時は ⚙の ✔（「地図だけ のこす」も できます）
・⚙「🛠️ 道具ボタンも かくす」→ 右がわの ボタンも 消えて 世界だけに なります。右上の ⊕（または H）で いつでも もどります＝もどれなく なることは ありません
・えらんだことは おぼえます（つぎに ひらいた時も そのまま）

🏔️ だいち（山と海）だけの あるきかた・とびかた
・W A S D → あるく。見おろしても 高さは かわりません（地面を あるく かんじ）
・Space を ぽん → ジャンプ（押した しゅんかんに 跳びます）
・Space を おしっぱなし → 跳んだ いきおいの まま 空へ のぼって いきます。はなすと のぼるのを やめて すべるように おりてきます
・空では 見ている向き へ とびます（マウスで 進む向きを えらぶ）
・Shift → 地面では はやく走る／空では さがる。スマホの ▲▼ は 空での 上下の びちょうせいです
・⚡とぶ ちから（画面の下）が なくなると のぼれなくなり、ゆっくり おりてきます。けがも やりなおしも ありません。足が 地面に つくと すぐ たまって また とべます
・スマホは 下まん中の 🦘 ボタン＝入切（いれきり）です。ぽんで ジャンプ／ながおし、または 空で もう一度おす と のぼりっぱなし（🚀のぼり中）＝指を はなしても のぼります。もう一度おすと とまります。⚡が なくなると ひとりでに とまります。右の まるを さわったまま のぼれるのは このためです
・この世界では 🛩️オートクルーズ は はたらきません（自分の 操作が いちばん）
